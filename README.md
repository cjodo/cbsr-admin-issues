# CBSR Admin: Issues and Feature Requests

This is where to report problems with the CBSR content admin, and to suggest
new features. The admin's code is kept private; this repository only holds
issues.

## Something isn't working

If something in the admin is broken, confusing or not doing what you expect,
[open a problem report](../../issues/new?template=bug_report.md).

It helps to include:

- what you were doing, and on which page
- what happened, and what you expected instead
- a screenshot, if you can

## Have an idea?

Feature requests are very welcome, big or small: a missing feature, a step
that feels slow, or something you keep doing by hand.
[Open a feature request](../../issues/new?template=feature_request.md).

Tell us what you'd like to do and why it would help. You don't need to know
how it would be built.

## Before you open an issue

- **Check [existing issues](../../issues)** in case someone has already
  raised it. If so, add a 👍 or a comment with your own details.
- **Don't include passwords, reset links or other private details.** Issues
  here are public.
- **Security problems:** please don't report them here. Contact the admin
  maintainers directly instead.

You'll need a free GitHub account to open or comment on an issue.
